# Vistigo by 444Video

Marketing site for **Vistigo**, 444Video's monitoring product, with a hub page and one page per product:

| Page | Path |
|------|------|
| Hub | `/` |
| Vistigo Maritime | `/maritime/` |
| Vistigo Broadcast | `/broadcast/` |
| Vistigo Infra | `/infra/` |

Type follows the 444Video website design system in Outline: **Inter** for everything (headings, body, nav and labels),
**IBM Plex Mono** only for data readouts. Both are self-hosted in `assets/fonts/`.

Static HTML generated by `build.py` (plain Python, no dependencies). Hosted on GitHub Pages from the `main` branch root, at **https://vistigo.cloud** (set by the `CNAME` file; DNS is in Cloudflare as two DNS-only CNAMEs to `444-video.github.io`).

## Structure

```
build.py                 generates every page - edit content here, then run it
index.html               hub (generated)
maritime/ broadcast/ infra/   product pages (generated)
assets/vendor/tabler/    Tabler UI kit 1.7.1 (MIT, tabler.io), unmodified
assets/css/site.css      fonts, per-industry palettes, diagram and readout strips
assets/img/              real Grafana screenshots from noc.444.video
assets/fonts/            self-hosted fonts and their licences
```

## Editing

1. Change the content in `build.py` (each page is one function).
2. Run `python3 build.py`.
3. Commit `build.py` and the generated HTML together.

## Rules followed

- 444Video colour bars and logo on every page; each product has its own palette and display face.
- UK English. Hyphens, not em dashes. Sentence case, no all-caps labels.
- Comux figures are attributed to "a UK multiplex operator" and never generalised.
- Screenshots are badged "Screenshot"; anything drawn is badged "Mock-up". Readout strips say "Example values".
